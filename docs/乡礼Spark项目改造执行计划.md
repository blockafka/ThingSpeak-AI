## 🎯 一、产品核心定位
### 1. 一句话价值主张
乡礼Spark是面向地方食品特产小商家/合作社/伴手礼店主的**零门槛小红书笔记一键生成工具**，完全匹配赛道三「社会服务/造种新体验」定位：
- 商家不需要懂内容运营、不需要懂AI、不需要做任何复杂选择
- 仅需填6个简单字段+可选上传自己拍的产品图，点一下生成
- 直接拿到「可以直接复制发布的小红书文案+自动排好最优顺序的配图+每张图的配套图注」
- 解决小商家"有好产品但不会做内容引流"的核心痛点，降低地方特产数字化营销门槛，助力乡村文旅和县域经济
### 2. 核心差异化优势（和通用AI/套模板工具的区别）
| 优势点 | 说明 |
|--------|------|
| 🔴 用户零决策 | 所有「选风格、用什么结构、配什么标签」的复杂决策全由后台自动完成，用户看不到任何「模板」「DNA」「风格」选项，比用美图秀秀还简单 |
| 🔴 多DNA融合拒同质化 | 后台维护可插拔「小红书特产爆款DNA库」，每个DNA拆解自近期真实高赞爆文；生成时自动匹配Top3 DNA加权融合（主DNA70%+两个辅助DNA各15%），不是单一风格硬套，内容自然不千篇一律 |
| 🔴 DNA库持续新鲜 | 后台可随时添加新流行风格、淘汰过时玩法，永远跟得上小红书最新流量逻辑，用户无感知 |
| 🔴 多模态真实感 | 结合用户上传的产品图自动识别细节，不会生成假大空营销套话，有真实体感、有地方性记忆点，不像通用AI写的"一看就是广告" |
| 🔴 输出100%可用 | 自动给图片按小红书最优顺序排版、自动生成每张图注，用户复制文案+按顺序传图就能直接发布，不需要任何额外调整 |
| 🔴 稳定不翻车 | 大模型生成+规则兜底双保险，不会出现通用大模型跑题、格式混乱、宣传违规的问题 |
| 🔴 路演可解释 | 演示时可展示后台「匹配了什么DNA、该风格平均点赞量、核心爆款特征」，技术逻辑清晰不是黑盒 |

## 🧬 二、爆款DNA库设计（用户完全无感知，后台维护）
### 1. DNA结构（每个DNA为独立JSON配置）
拆解自小红书食品特产类近期点赞1w+真实爆文，每个DNA包含：
- 适配场景：适合的品类、售卖场景（如闺蜜旅游风适合游客伴手礼）
- 结构特征：开头钩子写法、段落排布逻辑、结尾引导方式
- 语言特征：语气、用词偏好、emoji密度、热词使用习惯
- 标签偏好：该类爆文常用高流量标签组合
- 参考数据：该风格爆文平均点赞/收藏量
- 示例片段：1-2段真实爆文片段作为Few-Shot示例喂给LLM
### 2. v1内置DNA列表（共6个，覆盖95%以上特产场景）
| DNA ID | DNA名称 | 适配场景 | 平均参考点赞 |
|--------|---------|----------|--------------|
| bestie_travel_share | 闺蜜旅游分享风 | 游客伴手礼、景区特产 | 1.2w+ |
| local_recommend | 本地人良心推荐风 | 本地日常特色食品、自用尝鲜 | 8k+ |
| gift_guide | 送礼实用攻略风 | 节庆送礼、伴手礼礼盒 | 9k+ |
| cultural_story | 文艺治愈故事风 | 非遗、老手艺、古法制作产品 | 1.5w+ |
| weird_snack_review | 猎奇搞笑测评风 | 新奇小众、口味特殊特产 | 2w+ |
| healthy_snack | 健康零食测评风 | 低卡、无添加、健康类特产 | 7k+ |
### 3. DNA匹配与融合规则
策略分析器根据用户输入自动匹配Top3 DNA，完全不需要用户选择：
- 主DNA（70%权重，核心风格）：按售卖场景优先匹配：
  * 游客伴手礼 → 闺蜜旅游分享风
  * 节庆送礼/礼盒 → 送礼实用攻略风
  * 非遗/老手艺 → 文艺治愈故事风
  * 新奇小众特产 → 猎奇搞笑测评风
  * 健康/无添加零食 → 健康零食测评风
  * 本地日常食品 → 本地人良心推荐风
- 辅助DNA（各15%权重，补充细节）：根据产品卖点自动匹配2个补充风格（如主打无添加的伴手礼，辅助匹配健康零食风+本地人推荐风）
- 兜底机制：多DNA匹配失败自动退回单主DNA匹配，再失败退回规则默认，永不翻车
### 4. DNA运营规则
- 新增：发现新爆款玩法后，拆解3-5篇同类型高赞爆文总结共性，写成JSON放入`core/dnas/`目录即可生效，无需改核心代码
- 淘汰：每月盘点，淘汰流量下滑（同类平均点赞连续2个月低于5k）、玩法过时、和现有DNA重复度高于30%的冗余项

## 🔄 三、核心端到端数据流（Workflow）
```
用户输入（6个字段+可选传图）
    ↓
[策略分析器（大模型驱动+规则兜底）]
    → 自动匹配最适配的Top3爆款DNA
    → 输出匹配度、参考爆文数据、核心卖点、避坑规则、内容风格要求
    → 如果有图片，标记需要多模态处理
    ↓
[Prompt组装器（DNA驱动）]
    → 注入小红书特产文案写作规则、违规词避坑要求
    → 注入匹配到的爆款DNA全部特征+Few-Shot示例
    → 注入用户输入的产品信息、核心卖点
    → 如果有图片，将图片转base64作为多模态输入
    → 要求输出固定JSON格式
    ↓
[多模态LLM生成层]
    → 调用豆包doubao-seed-2-1-pro-260628接口
    → 3次重试+规则兜底（极端情况返回规则拼接的默认文案+默认图片排序，永不报错）
    ↓
[结果结构化处理]
    → 解析JSON、校验格式
    → 组装完整内容包：小红书标题+正文+标签+图片最优排序+每张图注
    ↓
前端展示
    → 模拟小红书真实笔记样式预览（直接用用户上传的图片按排序轮播）
    → 支持一键复制全文/标题/标签
    → （路演模式可选展示：匹配的DNA信息、参考爆文数据，体现技术逻辑）
```
